# Model and harness repairs

- The first core tests exposed a Quint test-harness behavior: `.fail()` leaves the next-state frame unassigned. Rejections are now asserted as terminal test steps, with state checks before rejection. Original failing logs remain under results/logs/initial-core-tests*. This is a harness repair, not a protocol counterexample.
- A reopening mutant initially retained a separate consumed-hold guard, so its final instruction was unreachable. Its retained no-counterexample result is not counted as a kill. The repaired isolated reopening mutation permits terminal identity reuse after the legitimate ABORT refund, and S02 then fails.
- The first core finalized facts only when their source predicate still held. That underrepresented historical snapshots. The model now stores immutable included facts at transaction execution and finalizes those independently of current state. This changes the semantic evidence input and invalidates prior safety runs for the expanded history behavior; affected core checks and mutants are executed on the revised model.
- Signatures now explicitly store the complete Descriptor rather than only an index into its immutable canonical template. Every bound field has an altered-instruction rejection case.
- The temporal model exposed a coverage omission during inspection: ABORT bookkeeping had no reconciliation action. Added recordAbort based on authenticated outcome knowledge and actual hold resolution. L04 covers both terminal outcomes.
- Trust verification now snapshots accepted root/checkpoint separately from subsequently received candidate inputs. This prevents a specification invariant from confusing an old accepted proof with a new rejected candidate. Rotation additionally requires three distinct predecessor-validator approvals.
- Java 11 rejected the new launcher and Java 20 rejected class version 65. The existing GoLand Java 25 runtime runs both backends; all failures remain visible. No global runtime change was made.

The source candidate was not silently rewritten. Reference v1 adds the explicitly requested persistent early-terminal knowledge and signed abort tombstone semantics. Native reservation durability, canonical history and legal intervention policy remain explicit assumptions/choices, not conclusions.

- Topology self-review found that the first generic B/D instances coupled A preparation with remote decision registration. They also read A freeze state in the B/D commit guard. The pre-repair model is retained in models/history/dvp-pre-topology-repair.qnt and its receipts remain historical. B/D registration is now a separate decision-ledger action; participant A reads only local terminal knowledge, and B/D commit guards use local checks plus authenticated preparation evidence. Shared execution checks both local holds directly. A-hosted reference transitions are unchanged by these host-conditional repairs; its observed greens retain their original boundaries. Affected B/D/shared variant checks must run on this repair.

This repairs the induction hypothesis rather than narrowing reachable protocol behavior.
