# Design

Use a finite native-hold core plus evidence, operational/control, relational privacy and timed resource models. Reuse descriptors and economic contracts across A/B/D variants. Preserve every counterexample before any repair. Run smoke controls first, then core witnesses/simulation/bounded/finite/temporal checks, then required variants, trust, privacy, timing and integrated configurations.

Models are abstractions; only checked mappings establish refinement, and safety mappings do not preserve liveness automatically. Candidate sources and model/tool revisions are identified in verification/sources and results/manifest.json. Full v2 scope remains NOT DONE until every mandatory suite has an executed result or a precise visible blocker.

## Independent review iteration

Review starts from exact base 4e3b8d0 and the original source request, not the author's asserted result. One reviewer retains IR-001–IR-004 through repair/recheck. Root owns code/spec/results and publication; reviewer owns independent-review.md/json. Privacy payload provenance is internal, while complete wire responses enter the relational trace. Historical model greens are retained when unchanged; comment-only deltas are explicitly recorded. New execution force, exact receipt selection, immutable native exports and the sealed proof contract prevent the demonstrated reproduction/audit defects. The seal is versioned local evidence, not third-party attestation.

Timing/capacity scopes remain separate: two-trade round-robin timing versus finite hostile FIFO service, with no invented priority or combined deadline theorem. Scope/failure controls are retained as results. Publication occurs only after reviewed repairs, current evidence, final clean-revision gate and remote readback. No archive, deployment or additional paid calls is implied.

## Comparative-review repairs

The original four findings are repaired at their actual observation boundaries. Returned payloads retain a separate immutable query/source/proof issuance context, with an independent per-field specification instead of a producer-derived expected body. The existing cryptographic proof set is separated from application admission by a source-derived external-program proof action; real COMMIT and independent S10 consume that context. A dedicated full financial/rotation/exit graph checks its rejection. Consumer-boundary fixtures additionally represent valid certificates for other contexts; they are input-contract tests, not claimed native-source attack executions.

Economic receipts share one typed schema across the financial core and the three-domain model. Local debit/delivery or reservation release emits the receipt atomically. Receipts include trade/leg/kind, chain/genesis, asset, account and quantity; scalar counters still detect duplicate financial operations. The oracle compares receipt fields against signed descriptor/institution terms without calling the output constructor. Native releases are availability changes to the original owner's account; escrow releases also move vault ownership back. A pure source-world ABORT monitor checks actual remaining obligations and refunded/absent disposition semantics independently of record shape. It is an assertion, not a remote live-state guard added to the consumer.

Original model checking evidence remains immutable and proves its original abstraction. Strengthened predicates/outputs require current native safety and conditional temporal observations; unrelated standalone timing, capacity, trust, authentication, membership and algebraic-core checks are reused. All heavy checkers run sequentially under explicit wall/heap/worker limits. The follow-up review must reconcile every property and source file and must not infer production, legal, cryptographic or arbitrary-configuration conformance.
