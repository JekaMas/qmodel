# Design

Use a finite native-hold core plus evidence, operational/control, relational privacy and timed resource models. Reuse descriptors and economic contracts across A/B/D variants. Preserve every counterexample before any repair. Run smoke controls first, then core witnesses/simulation/bounded/finite/temporal checks, then required variants, trust, privacy, timing and integrated configurations.

Models are abstractions; only checked mappings establish refinement, and safety mappings do not preserve liveness automatically. Candidate sources and model/tool revisions are identified in verification/sources and results/manifest.json. Full v2 scope remains NOT DONE until every mandatory suite has an executed result or a precise visible blocker.
