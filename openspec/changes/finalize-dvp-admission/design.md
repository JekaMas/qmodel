# Design

The first finalized reservation on either native ledger is the admission boundary. A continuation is rooted in a canonical proof for the exact descriptor. The previous-state observer separately remembers the finalized set at the cut. This prevents two provisional reservations from giving each other historical authority. A timed-out provisional hold has an authenticated recovery path.

One local block includes an eligible request generation. A later block supplies the configured confirmation depth. The bank maintains a monotone verified cursor and may also serve explicitly historical reads. Historical certificate verification is distinct from accepting new work under the current validator composition.

A settlement comparison uses both actual native deliveries as its success condition. The honest committee requires availability and fair application on B, as does the remote leg of the A-hosted reference. Thirty-six bilateral shortfall histories compare independent orders and economic postconditions against actual bookings. Each source and consumer retains its own authority boundary.

A hosts the PoC decision. Both banks still need to qualify the cash entitlement and enforcement during B unavailability. Common execution or an equivalent cash-finality mechanism is required if only credit on B is payment. This repository contains model results and authenticated-input SQLite tests. Bank contracts, deployed QBFT, circuits and EVM conformance remain external.
